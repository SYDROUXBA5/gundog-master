# Gundog Master

Breed identification drill for the 58 gundogs — pointers and HPR breeds, setters,
spaniels, retrievers and water dogs. A study companion for the Highland Canine
Master Trainer course.

**Live: https://sydrouxba5.github.io/gundog-master/**

Six modes: Breed ID, Knowledge, Reverse, Learn, Look-alike duel, Collection.
XP, levels, day streaks and per-breed graduation, saved per student in the
browser. Single self-contained file — no build step, no network calls.

Sibling of [hound-master](https://github.com/SYDROUXBA5/hound-master) and
[working-master](https://github.com/SYDROUXBA5/working-master), which share the
same engine.

`build/` holds the pipeline that generates `index.html` — see `build/README.md`.
